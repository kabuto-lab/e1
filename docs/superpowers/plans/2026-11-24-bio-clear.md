# Очистка био в анкете — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Пустое био при сохранении очищает био в базе — из админки и из «Моей анкеты».

**Architecture:** Обе формы всегда отправляют `biography` в `PUT /models/:id`: обрезанный текст или `null`, если после `trim` пусто. Бэкенд уже записывает `null` как `NULL` (проверено), его не трогаем.

**Tech Stack:** Next.js, React, react-hook-form, TypeScript.

**Spec:** `docs/superpowers/specs/2026-11-24-bio-clear-design.md`

## Global Constraints

- Бэкенд не трогаем. Новых зависимостей нет.
- Пустое значение — `null`, не `""` (из-за `biography ?? description` в `app/models/[slug]/layout.tsx:19`).
- Старые строки не удаляем — комментируем рядом с пометкой `2026-11-24: пустое био отправляем null, иначе бэк не очищает поле`.
- Ничего, кроме `biography`: остальные поля, которые так же не очищаются, — вне задачи.
- Не коммитить, не `git add`: пользователь проверяет рабочую копию сам.

## Review Focus

1. Био из одних пробелов → сохраняется как `NULL`, а не как `"   "`. — ручная проверка Task 1.
2. Сохранение, когда био не трогали (непустое) → значение не меняется. — ручная проверка Task 1.
3. После очистки и сохранения форма не помечается «есть несохранённые изменения» и после перезагрузки поле пустое (а не `"null"`). — ручная проверка Task 1.
4. Публичная страница модели без био → блока «О себе» нет, описание страницы — запасное. — ручная проверка Task 1.
5. Публикация/черновик (`publishMode`) в админке очищают био так же, как обычное сохранение. — ручная проверка Task 1.
