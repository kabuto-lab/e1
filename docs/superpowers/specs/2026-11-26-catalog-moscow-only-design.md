# Каталог: временно только Москва — дизайн (малое изменение)

**Зачем:** анкеты есть только в Москве; кнопки «Санкт-Петербург», «Казань», «Сочи» в каталоге ведут в пустую выдачу. Скрыть их временно.

**Цели:** в ряду фильтров `/models` — «Все · Москва · | Фильтры».
**Не цели:** анкета модели (селект «Город» остаётся с полным `CITIES`), бэкенд, БД.
**Анти-цель:** потерять остальные города безвозвратно — вернуть должно быть правкой одной строки.

**Подходы:**
1. *Отдельный `CATALOG_CITIES` в `lib/cities.ts`* — выбран: каталог и анкета развязаны, вернуть легко.
2. Урезать `CITIES` — отвергнут: ломает селект анкеты.
3. Динамически по городам из базы — отвергнут: фронт видит лишь страницу выдачи (15 шт.), нужен новый эндпоинт, бэкенд заморожен.

**Решение:** `CATALOG_CITIES = ['Москва'] as const satisfies readonly City[]` (комментарий «временно»); `ModelsClientPage.tsx` рендерит кнопки из `CATALOG_CITIES`. Кнопка «Все» остаётся.
