## Подготовка

Нужны Node.js22, npm10.9.0 и включённый Docker с Compose.
Архив с базой распакуй рядом с папкой MyMuse. Внутри папки
MyMuse-handoff-2026-11-23 должен находиться mymuse-development.dump.

```sh
git clone https://github.com/kabuto-lab/e1.git MyMuse
cd MyMuse
git switch -c feature/my-task
node docs/handover/generate-env.mjs .
docker compose --env-file .env -f docs/handover/compose.dev.yml up -d
npm ci
```

Скрипт создаёт новые локальные пароли PostgreSQL/MinIO и ключи JWT/шифрования.
Существующий .env он не перезаписывает. Боевых Т-Банка, Telegram и TON в нём нет.
SMTP направлен в Mailhog. Все порты сервисов доступны только через127.0.0.1.

После готовности PostgreSQL:

```sh
docker compose --env-file .env -f docs/handover/compose.dev.yml ps
node docs/handover/restore-db.mjs . ../MyMuse-handoff-2026-11-23/mymuse-development.dump
npm run build --workspace=@escort/db
node docs/handover/init-storage.mjs .
npm run build
npm run dev:apps
```

Восстановление разрешено только в пустую локальную БД. Скрипт не удаляет таблицы.
Не запускай seeds, bootstrap или db:push поверх полученного снимка.

Сайт: http://localhost:3001.
Вход администратора: http://localhost:3001/admin-login.
Логин и пароль локального администратора находятся в DEV-ACCESS.txt из архива.
Эта учётная запись не существует на рабочем сайте.

Проверка API: http://127.0.0.1:3000/health.
PostgreSQL:127.0.0.1:15434, база и пользователь mymuse_dev; пароль в локальном.env.
MinIO:127.0.0.1:19004, консоль19005. Mailhog: http://127.0.0.1:18026.

## Копия базы и фотографии

В dump сохранены таблицы, связи, опубликованный каталог, цены и бронирования.
Действующие пароли, сессии, восстановление доступа, Telegram-привязки,
контакты, личная переписка и реквизиты платёжных операций убраны или заменены.
Полная production-копия хранится отдельно у владельца.

Сами фотографии и видео в dump не входят. Часть публичных ссылок сохранена.
Новые загрузки должны идти в локальный MinIO. Архив, dump, DEV-ACCESS.txt,
ключи и .env не добавляются в Git. Это очищенная рабочая копия, а не необратимо
анонимные данные: публичные фото и некоторые идентификаторы сохранены.

## Проверки и внешние сервисы

CI выполняет все API/Bot suites, проверки frontend-целей и полную сборку DB/API/Bot/Web.
Проверки отзыва сессий используют отдельную PostgreSQL security_auth_test.
Не подставляй production URL в SECURITY_TEST_DATABASE_URL.

Telegram на рабочем сайте: @my_muze_bot. Для разработки создай другого бота.
Т-Банк подключён к боевому терминалу, но для разработки нужен тестовый терминал.
Связь с банком и webhook проверены, настоящий платёж картой не проверялся.
Локальные действия не должны попадать в счётчик Метрики111497387.

Production работает через nginx и systemd mymuse-api/mymuse-web.
Активный путь: /opt/mymuse-deploy/current. Доступы к серверу, production-БД,
админке и панели публикации не входят в архив разработчика.
Старые PM2/vps:after-pull инструкции не использовать.
