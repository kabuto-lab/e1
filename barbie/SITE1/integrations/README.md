# NAS · Integrations

Каталог внешних интеграций платформы NAS (чат-виджеты, мессенджеры, аналитика, CRM).
Каждая интеграция — отдельный план/спека в этой папке; код живёт в `apps/api` (приём
вебхуков) и `apps/web` (виджеты/сниппеты на публичных сайтах тенантов).

## Принципы
- **Per-tenant**: интеграция включается и конфигурируется отдельно для каждого тенанта
  (ключи/токены — в `tenants.settings` jsonb, не в коде, не в git).
- **Webhook-first**: внешние события принимаем своим эндпоинтом, верифицируем секретом,
  кладём в свою БД (лиды/сообщения), дальше — наша логика.
- **Не money-path**: чат/виджеты не трогают escrow и платежи (их в NAS нет).
- **Spine не трогаем**: новые таблицы/миграции — только с OK оператора.
