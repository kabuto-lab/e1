## 0. Миссия аспекта

Сделать **бренд каждого тенанта** (для эталона — `barbiespa`) **доминирующим источником в своей нише и гео** во всех поисковых экосистемах. Позиции и трафик — следствие; цель — **авторитет, доверие, сила сущности (entity), доля цитирований в ИИ-ответах, заявки**.

**Золотой закон.** Любое решение должно усиливать хотя бы одно из:
User Satisfaction · Search Understanding · Authority · Trust · Entity Strength · Information Gain · Discoverability · AI-Citation Probability · Conversion.
Не усиливает ничего — отклонить. Опирается на трюк/лазейку — отклонить.

**Запрет (forbidden thinking):** никаких трюков, шорткатов, временных лазеек. На основном бренде тенанта — **только white-hat**. Чёрные приёмы (клоакинг, дорвеи, PBN, скрытый текст, накрутка ПФ) на adult/YMYL = экзистенциальный риск деиндекса; на боевом бренде — никогда.

## 3. Core engines (рабочие движки)

- **[Search-Intent]** Классифицировать каждый запрос: Informational · Commercial · Transactional · Navigational · Local · Investigative. Одна страница = один доминирующий интент; несовместимые не мешать.
- **[Topical Authority]** Карта ниши: Topic → Subtopics → Microtopics → Questions → Entities → Content Assets. Экспертом темы должен быть **весь сайт тенанта**, а не одна статья.
- **[Information Gain]** Всегда добавлять НОВУЮ ценность: данные, собственный опыт, фото-доказательства, методики, цифры. Никогда не рерайтить конкурентов и не лить low-value AI-наполнитель.
- **[Entity]** Идентифицировать Main / Supporting / Related / Competing сущности + сигналы Knowledge Graph. Усиливать через Schema (Organization/LocalBusiness/Person/Service/Article), единый NAP, упоминания, соцсети, брендовые запросы.
- **[GEO]** Инженерить контент так, чтобы ИИ его **извлёк, суммировал и процитировал**: явные атомарные проверяемые утверждения, именованные сущности, цифры/даты, структура «Вопрос → краткий ответ → детали», машинно-чистая разметка.
- **[AEO]** Брать Featured Snippets / People-Also-Ask / голосовой: прямой ответ 40–60 слов в начале, потом глубина; списки, таблицы, определения, FAQ-схема.
- **[E-E-A-T]** Реальные авторы+био+регалии, кейсы, first-hand доказательства (фото интерьера/процесса/результата), источники, прозрачность, репутация вне сайта. Критично для YMYL/sensitive.
- **[AI-Citation]** Структурировать цитируемые блоки: Definition → Explanation → Evidence → Example → Summary → Key Takeaway. Создавать факты, которые удобно цитировать.
- **[Technical]** Crawlability, indexability, CWV (LCP<2.5с / INP<200мс / CLS<0.1), canonical, redirects, sitemap, robots, SSR/SSG-рендер, чистая архитектура, ноль дублей.
- **[Brand]** Растить брендовые запросы, упоминания, узнаваемость, брендовый CTR.
- **[Conversion]** Трафик без конверсии неполон: CTA, trust-сигналы, трение UX, ясность, микроконверсии. Убеждение — только на правде.
- **[Content Intelligence]** Оценивать каждый ассет 0–100: Relevance 20 · Depth 20 · Originality 20 · Authority 15 · Structure 10 · Trust 10 · Citation 5. Гейт: отвечает на запрос? покрывает тему? добавляет новое? показывает реальный опыт? можно действовать? может ИИ процитировать?

## 4. Яндекс / RU-модуль (рынок — Россия)

Яндекс сильнее Google весит **поведенческие** (dwell, возвраты, pogo-sticking, удовлетворённость), **коммерческие** (цены, контакты, наличие, гарантии, оплата, выезд, отзывы) и **региональность**.
Алгоритмы: Матрикснет, Палех, Королёв, Андромеда, YATI. **Нейро** — цель GEO.
Брать: Яндекс.Бизнес + Карты + отзывы; задать регион (Москва).
Фильтры-капканы: **Баден-Баден** (переоптимизация текста), **Минусинск** (покупные ссылки), **АГС** (малополезные/сетки), фильтр за **накрутку ПФ**, **аффилиат-фильтр** (несколько сайтов одного бизнеса под один запрос → останется один).

## 5. Risk & Resilience

Знать white/grey/black и как движки их ловят. Оптимизировать под **системы и резилиенс**, не под лазейки. На боевом бренде — никогда черное. Защита от negative SEO: мониторинг ссылок (Disavow в Google), мониторинг ПФ/Метрики на аномалии, защита форм (капча/антибот), бэкапы, отслеживание копий, работа с отзывами.

## 6. Niche adaptation — spa/adult, Москва, РФ (всегда первым шагом)

- Рынок RU → **движок-приоритет Яндекс** (Google вторым).
- Ниша **YMYL/sensitive + adult**: доверие алгоритмов низкое, набирается медленно; модерация Карт режет по тематике — формулировать услуги аккуратно («спа/массаж/релакс»), не нарушая правила площадок.
- **Платная реклама (Директ/Google Ads) для 18+ почти закрыта** → органика + локалка + поведенческие + конверсия становятся ГЛАВНЫМ каналом. Тем ценнее white SEO.
- **Не плодить клоны** одного салона под один запрос (аффилиат-фильтр). Разные бренды/тенанты — ок; один бренд на N доменов под один запрос — нет.

### Рекомендованный «честный» стек под нишу
1. Техничка идеальна (CWV, WebP, индексация, Schema LocalBusiness+FAQ+Review) — у NAS Next.js SSG, база сильная.
2. Семантика по интентам: коммерческие (программы, выезд, метро/районы) + информационные (раздел «Статьи»).
3. Локалка: Яндекс.Бизнес + 2ГИС/Zoon + гео-страницы под метро/районы + реальные отзывы.
4. Контент-хаб «Статьи» → перелинковка на коммерческие страницы и на запись; обновлять, добавлять FAQ.
5. Реальные ПФ: цепляющие сниппеты, мгновенная загрузка, удобная запись, квиз-подбор, виджеты связи.
6. CRO/NLP на посадочных: офферы (счастливые часы, +30 мин), соц-доказательства, иллюзия выбора в формах — **на правде**.
7. Ссылки осторожно: крауд + тематические статьи + агрегаторы; без массовой покупки анкоров.

## 7. Конверсия / NLP (трафик → заявки; на правде)

- **Структуры:** AIDA · PAS · BAB · 4U-заголовки (Useful, Urgent, Unique, Ultra-specific).
- **Триггеры Чалдини:** дефицит/срочность, соц-доказательство, авторитет, взаимность, обязательство, симпатия.
- **Лингвистика (мягко):** пресуппозиции, встроенные команды, якорение, рефрейминг, двойная связка/иллюзия выбора, сенсорная лексика.
- **CRO:** один явный CTA выше сгиба + повторы; короткие формы (имя+телефон), click-to-call, мессенджеры; якорение цены (decoy); квиз-подбор; trust (конфиденциальность, отзывы, «как проходит визит»); A/B по заявкам, не кликам.
- **Этика (жёстко):** фейковые «осталось 1 место»/таймеры, ложные отзывы и обман — нарушение закона о рекламе + репутационный риск. Триггеры опираются только на правду.

## 9. Протокол решения (на каждую рекомендацию)

1. Улучшает удовлетворённость? 2. Discoverability? 3. Authority? 4. Trust? 5. AI-citation probability? 6. Entity strength? 7. Долгосрочную видимость? — если квалифицируется несколько, выбрать максимальную долгосрочную ценность.

## 10. Применимость к NAS (где это живёт в коде)

- **Контент-хаб «Статьи»** — `apps/web/src/components/tenant-sites/<tenant>/articles.json` + `BarbieArticles*`, роуты `(tenants)/<tenant>/stati[/slug]`. Сейчас (для barbiespa) — 38 статей, scraped-рерайт с barbiespa.ru, **низкий Information Gain, без Schema/FAQ/структуры** → главная зона роста.
- **Schema/JSON-LD, sitemap, robots, hreflang, метаданные** — на уровне Next.js (`generateMetadata`, route handlers). Часть ещё не внедрена.
- **Коммерческие посадочные** — `programmy`, `vyezd`, `models`, `malchishnik`, `vacancies`.
- **Изображения** — мандат `.webp` по всей системе (см. memory `asset-format-webp`); это совпадает с Image-SEO требованием арсенала.
