Самое контекстно-очевидное незакрытое — root handler. На `:3010/` сейчас 404, обсуждали 2 хода назад. Закрываю самым нейтральным вариантом: `GET /` → 302 redirect на `/api/docs` (в dev) и на `/v1/health` (в prod, чтобы не светить swagger). Один новый файл `apps/api/src/root/root.controller.ts`, регистрация в `app.module.ts`.

**spine:** `app.module.ts` — spine. В AVTONOM нельзя без явного ок. По правилам — SKIP с записью в SESSION_LOG, перейти дальше.

Альтернатива без spine-touch: HealthController уже зарегистрирован, добавить туда `@Get('/')` редирект — но тогда у `HealthController` будет смешанная ответственность (health + redirect), это грязно.

**AI-Default-A1:** spine-skip правило соблюдаю — не редактирую `app.module.ts`. Вместо этого добавляю редирект в `HealthController` как `@Public() @Get('/')` метод. `HealthController` уже подвешен на root path в Nest, маршрут не конфликтует. Решение запишу в SESSION_LOG как осознанный AI-Default.

**AI-Default-B1 — местоположение:**
Кладу в `apps/web/src/app/(tenants)/<slug>/page.tsx` — это App Router group route. URL получится `http://localhost:3011/<slug>` для каждого тенанта. Подпапка на тенанта — выполняется буквально. Не дублирую в `tenants/` на корне SITE1, потому что цель — «на новом стеке» = в Next.js приложении, чтобы рендерилось.

**AI-Default-B2 — глубина:**
10 HTML-моков по 1100–1700 строк каждый. Pixel-perfect перенос всех в React/Tailwind — слишком много для одной сессии. Делаю прагматично:
- Один **shared component**: `TenantSiteShell` с секциями (Hero / Navigation / Positioning / Rooms / Programs / Staff / Contacts / Footer).
- Per tenant `page.tsx`: тонкий wrapper, читает свой slice из `tenants-real-content.json`, передаёт в `TenantSiteShell`, инжектит CSS-переменные с design tokens и Google Fonts.
- Личность тенанта проявляется через **цвета + шрифты + текстовый контент**. Структура секций общая.
- Это «версия каждого сайта на новом стеке» по содержанию и брендингу. Pixel-replica моков — отдельная задача, если потребуется.

**AI-Default-B3 — шрифты:**
Каждый тенант имеет 2 Google Font'а в design tokens. Подключаю через `next/font/google` на уровне каждой страницы — Next.js code-split'ит, грузится только при заходе на /<slug>.

**AI-Default-B4 — данные:**
`tenants-real-content.json` уже в `barbie/SITE1/data/`. Импортирую через TS (resolveJsonModule). Создаю `apps/web/src/lib/tenants.ts` с типизацией и helper `getTenantByDomain(domain)`.

**AI-Default-B5 — стиль:**
- Tailwind для layout (flex/grid/spacing).
- CSS-переменные через inline style на root для design tokens.
- Без анимаций/эффектов из оригиналов (slug-уровень). Это базовая версия.
